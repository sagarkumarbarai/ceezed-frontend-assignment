# 🚀 CeeZed Technologies - Frontend Assignment

This repository contains the solution for the Frontend Development Assignment for CeeZed Technologies.

The project consists of three fully responsive HTML pages built using Tailwind CSS, inspired by the clean, professional aesthetic of modern enterprise websites (such as SAS).

## ✅ Live Preview

To view the live demo of this assignment, please open the `index.html` file directly in any modern web browser or use a live server extension.

## 💻 Project Structure

The repository includes the following files:

* **`index.html`**: The main Landing Page, featuring the Hero Section, Insights/Trending Topics, Industry Solutions, Navigation Bar, and Footer.
* **`about.html`**: A bonus page covering the company's mission, vision, and core team.
* **`contact.html`**: A bonus page containing a functional Contact Form and essential corporate contact details.

## 🛠️ Technology Stack

* **HTML5:** Used for the semantic structure of the web pages.
* **Tailwind CSS (CDN):** Utilized a utility-first approach for rapid development, ensuring a modern and responsive design across all screen sizes.
* **JavaScript (Vanilla JS):** Used sparingly only for the mobile navigation menu toggle functionality.

## 💡 Design Approach and Highlights

1.  **SAS Inspiration:** The design, layout, and color palette were influenced by the SAS website to achieve a clean, data-focused, and professional enterprise look.
2.  **Responsiveness:** All pages are fully responsive, implemented using Tailwind's built-in breakpoints (`sm:`, `md:`, `lg:`).
3.  **Consistency:** The Navigation Bar and Footer are consistently applied across all three pages to ensure a unified user experience.
4.  **Custom Colors:** Custom brand colors (`primary`: Indigo-600, `secondary`: Emerald-500) were configured using Tailwind's configuration script.
